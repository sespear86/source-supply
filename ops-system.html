Solopreneur ops system

Use this as a closed loop for one calendar week. Do not add a second revenue project until the week’s one revenue task ships or is killed in writing.

Sunday night — load the week

  1. Write three lines: money in, money out, one bottleneck.
  2. Pick one revenue task that a stranger can pay for without a meeting.
  3. Name the kill date. If it is not shipped or killed by then, it is a miss.

Daily — thirty minutes

  1. Inbox to three buckets: do today, later this week, ignore. Empty the ignore bucket.
  2. Work the revenue task before any page-pretty work.
  3. Log one sentence: shipped, blocked, or skipped. Skipping twice in a row is a kill vote.

Friday — close the books

  1. Count hours on the revenue task vs hours on tooling.
  2. If tooling won, next week’s task is a sale, not a refactor.
  3. Publish one public artifact or write why you did not.
